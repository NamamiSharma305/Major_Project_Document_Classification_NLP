---

## 🎯 Project Objective

The main objective of this project is to automatically classify text documents into different categories using **Natural Language Processing (NLP)** and **Machine Learning** techniques.

The system takes a text document as input, processes and cleans the text, converts the text into numerical features using **TF-IDF**, and then predicts its category using a trained machine learning model.

---

## 📝 Project Description

Document classification is an important application of Natural Language Processing.

In this project, a dataset containing text documents from different categories is used. The text data is cleaned and converted into numerical form using TF-IDF Vectorization.

Different machine learning algorithms are trained and evaluated for classification.

The categories used in this project are:

- Sports
- Technology
- Business
- Education
- Entertainment
- Politics
